# Записаний голос (необов'язково)

Якщо покласти сюди MP3-файли, застосунок програватиме їх замість синтезатора мовлення.
Для кожної фрази, якої немає у файлах, і далі працює синтезатор (або вібро-імпульси).

## Як додати

1. Покладіть файли в папку мови: `uk/`, `en/` або `ru/`.
2. Перелічіть їх у `index.json`, наприклад:
   `{ "files": ["uk/inhale.mp3", "uk/topup.mp3", "uk/exhale.mp3"] }`
3. Збільште номер версії кешу в `sw.js` (`anchor-v4` → `anchor-v5`).

## Назви файлів

| Файл | Фраза (укр.) |
|---|---|
| `inhale.mp3`, `topup.mp3`, `exhale.mp3` | «Вдих», «Ще трохи», «Видих» |
| `m1t.mp3`, `m1r.mp3` … `m3t.mp3`, `m3r.mp3` | інструкції м'язового етапу (напруга / розслаблення) |
| `g5.mp3`, `g4.mp3`, `g3.mp3`, `g2.mp3`, `g1.mp3` | інструкції заземлення |
| `n-100.mp3` … `n-0.mp3` | числа зворотного відліку |
| `w-0.mp3` … `w-89.mp3` | слова режиму «Образи» — за порядком у списку `WORDS` в `app.js` |

Точні тексти фраз для кожної мови — у словнику `I18N` в `app.js` (ключі збігаються з назвами файлів;
для дихання це `vInhale`, `vTopup`, `vExhale`).

Мінімальний набір — три файли дихання для однієї мови. Записуйте тихо, повільно, без музики,
з короткою тишею на початку й у кінці; гучність застосунок знижує сам.
